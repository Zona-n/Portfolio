🏆 Storytelling Award NASA Space Apps 2025

Brickonaut

A semantic research dashboard for 600+ NASA bioscience publications.

NASA has run hundreds of biology experiments in space, and the findings are scattered across publications nobody has time to read. I built the backend that ingests them, embeds them, and answers questions like "what do we actually know about bone loss in microgravity — and where do studies disagree?"

  • Flask + pandas ingestion pipeline over 608 publications, with Azure OpenAI and the Semantic Kernel SDK doing summarization and insight extraction.
  • Persona dashboards for scientists, program managers, and mission architects — each surfacing a different cut of the same corpus.
  • A consensus meter and gap map built with D3.js so users can see agreement and blank spots at a glance.
  • I led the storytelling for the demo, which won our panel at NASA Space Apps Chicago.
PythonFlaskpandasAzure OpenAISemantic KernelD3.js

02
Discovery Partners Institute Summer 2025

iHEATRISK

A heat-risk recommendation system that tells people what to actually do.

Extreme heat kills more people in the US than any other weather event, and most public guidance is generic. I built a classifier that reads a person's health profile, work setting, and living conditions, then returns recommendations grounded in real research rather than a one-size-fits-all warning.

  • Read 50 research documents on heat risk, extracted the interventions, and categorized them into 5 types: hydration, activity & rest, environmental control, monitoring, and medical care.
  • No training data existed, so I generated 500 realistic user profiles with pandas, NumPy, and Faker — modeling demographics, chronic conditions, BMI, medications, and cooling access.
  • Trained a scikit-learn Random Forest to predict risk across five levels, then wrapped it in a Flask API serving the iHEATRISK site.
Pythonscikit-learnRandom ForestpandasNumPyFakerFlask

● In progress Chicago Sprinterns 2026

CloudPulse

A grounded RAG agent that keeps up with Google Cloud release notes so engineers don't have to.

Cloud platforms ship changes faster than anyone can read them. CloudPulse ingests the live release-notes ledger and answers questions about what changed, grounded in official documentation instead of the model's memory.

  • Built the data layer: a BigQuery extraction pipeline over the public release-notes dataset, automated in the cloud so there's no manual ingest step.
  • Implemented Vertex AI RAG grounding against a corpus of Google Console documentation, plus a Vertex AI Search data store fallback for official docs.
  • Combined RAG retrieval and datastore search in one tool layer with keyword fallback, so answers degrade gracefully instead of hallucinating.
